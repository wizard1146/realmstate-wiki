Guide pages are HTML files in content/. Edit one on GitHub and open a pull request; the build checks every link.

  • Don't type game numbers into guide pages. Write {{name}} and the build fills in the current age's number (the list is in content/_values.json).
  • Pages marked generated: tools/sync.py are made from the game's rule files. Change the game's rules instead, then run python3 tools/sync.py.
