The game has an official HTTP API, so tools never need to scrape pages. It sends and receives JSON.

RequestWhat it does
GET /worldAge, current time, tick count, number of provinces
GET /rulesThe age's slots, definitions, fingerprints and numbers
GET /rankingsThe 100 largest provinces by land
GET /provinces/{id}One province
POST /commandsSend an action (below)

Commands

{"type": "create_province", "name": "Test Keep", "race": "dwarf", "personality": "sage"}
{"type": "explore", "province": 0, "acres": 20}
{"type": "train", "province": 0, "unit": 2, "count": 100}
{"type": "attack", "attacker": 0, "target": 5, "units": [100, 0, 50, 0]}

Races and personalities are named by identity. Units are numbered by slot: 0 offense, 1 defense, 2 elite, 3 thief. A refused action returns status 422 with an error message.

Reads may lag the game by up to a quarter of a second. Accounts, per-player access and rate limits come in a later milestone; until then every province is public.
