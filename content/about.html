The Realmstate wiki is built alongside the game. The rules pages (races, personalities, buildings, rites, operations, ages and more) are generated from the game's rule files, so they always match what the game does.

The guide pages are written by hand and pull their numbers from the current age, so they update when the rules do.

The site is built with the same tools as Scriptorium: plain HTML pages, a small Python build, and GitHub Pages.
